乡声 — 数据来源与合规说明
================================================

〇、文化知识库（主方向，data/culture_kb.json）
乡声 AI 导览的核心资料库为【团队整理的示例内容】。示例村落「青溪村·竹编技艺与古村文化」为设定场景，14 条资料由团队按公开资料风格整理编写，逐条标注：
  - 来源类型：公开资料整理(示例) / 地方志体例改写(示例) / 团队示例采写(待核验) 三类，均非真实采访记录；
  - 整理时间、授权范围（示例/教学演示用途）与人工审核状态（审核人、状态、备注）；
  - 版本记录见文件 versions 字段。
全部为【示例 / 待实地核验】内容，不得作为真实历史事实或已核实地方志引用。涉及真实地名、人物、机构、肖像、声音或个人信息时，须另行取得授权并遵循相关规定后方可接入。评估问题集 data/eval_questions.json 为团队设计的示例测试集，不代表真实用户测试。

一、数据性质（辅助看板）
辅助数据看板（/dashboard.html）所用 8 个 CSV 与 GeoJSON 为【合成示例数据 (synthetic sample data)】。此外有一份独立的世界银行 WDI 中国全国宏观背景数据快照（data/world_bank_china_rural_context.csv），属于真实公开统计，不是县级数据，不与虚构县域样本合并分析。
由 data/gen_data.py 使用固定随机种子 (SEED=20261011) 按统计规律程序化生成,
确保任何人重新运行脚本都能得到完全一致的数据集 (可复现、可核验)。

二、生成口径
数据字段与量纲参照以下公开统计口径设计 (仅为口径参考, 数值非真实抽取):
  - 《中国农村统计年鉴》《中国县域统计年鉴》常见指标口径;
  - 国家乡村振兴"五大振兴"框架 (产业/人才/文化/生态/组织);
  - 国家统计局农村居民人均可支配收入、森林覆盖率等指标定义。
趋势假设 (如脱贫攻坚后 2021 年贫困发生率归零、2020 年文旅受疫情冲击、
电商年度季节性峰值在 6/11 月) 用于演示分析与预测能力。

三、县域名称
青溪/云岭/丰禾/石门/临江/和顺 均为【虚构县名】, 不指向任何真实行政区划,
以避免与真实县域真实数据产生混淆。

四、合规承诺
  - 未爬取、未使用任何真实个人信息或受限数据;
  - 若后续接入真实公开数据, 将严格标注来源 (如国家统计局、各省统计年鉴),
    并遵守其开放数据使用许可。WDI 快照按世界银行开放数据许可使用；提交时应保留来源和指标代码，并核对当期许可条款。

五、真实宏观数据来源与口径
来源：World Bank, World Development Indicators (WDI)，中国（CHN），年度 2015–2025。
  - SP.RUR.TOTL：农村人口总量（人）
    https://api.worldbank.org/v2/country/CHN/indicator/SP.RUR.TOTL?format=json&per_page=100
  - SP.RUR.TOTL.ZS：农村人口占总人口比例（%）
    https://api.worldbank.org/v2/country/CHN/indicator/SP.RUR.TOTL.ZS?format=json&per_page=100
  - NY.GDP.PCAP.CD：人均 GDP（现价美元/人）
    https://api.worldbank.org/v2/country/CHN/indicator/NY.GDP.PCAP.CD?format=json&per_page=100
WDI 农村人口口径遵循其元数据/国际定义，不能直接等同于中国统计制度中的乡村人口；人均 GDP 为现价美元，受汇率和价格影响，不是实际增速。CSV 是接口观测快照，完整历史值、定义及修订以 WDI 在线数据为准。WDI 数据依世界银行开放数据许可提供，引用时注明来源及指标代码。
本次数据由世界银行 API 返回并整理为本地 CSV；国家统计局 easyquery 接口访问返回 HTTP 403，未纳入作品。

生成方式: python data/gen_data.py；真实数据快照文件：data/world_bank_china_rural_context.csv
