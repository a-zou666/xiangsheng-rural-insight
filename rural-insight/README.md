# 乡声 · 乡村文化 AI 导览创作助手

> 2026 第十四届全国大学生数字媒体科技作品及创意竞赛参赛作品
> 主推类别：AIGC 类数字创意作品创作赛项（AIGC 智能助手与交互体验）；主题贴合「数字文化传播 / 乡村振兴·农文旅融合」

面向到访游客与研学学生的**可信**乡村文化讲解助手：用户用中文提问地方文化、非遗、景点与农产品，系统**先检索团队整理并标注来源的本地资料，再组织带编号引用的答案；检索不足时明确拒答「资料不足」，不编造历史事实**。支持分龄/研学/双语讲解改写、离线语音导览、点位路线浏览、人工审核台与可复现评估面板。

**纯软件、默认功能无需联网、零第三方运行时依赖**（Python 标准库 + 原生前端 + 浏览器 Web Speech API）。

> 诚实边界：示例村落「青溪村」为**设定场景**，全部资料由团队按公开资料风格整理编写，逐条标注来源类型、授权范围与人工审核状态，均为**【示例 / 待实地核验】**内容，不得作为真实历史事实或已核实地方志引用；本作品**尚未经真实用户或当地场馆验证**。接入真实资料前须取得授权并核验。

## 一、核心能力（主方向）

| 能力 | 说明 | 可信/工程要点 |
|------|------|----------------|
| 🔎 检索增强可信问答 | 中文提问 → BM25 检索本地资料 → 充分性判定 → 带编号引用作答 | 纯 Python 手写 BM25（中文单字+二元切分），每条答案附来源名称/类型/审核状态；可观测可复算 |
| ⛔ 不足即拒答（抗幻觉） | 相关度或主题覆盖率低于阈值时拒答「资料不足」 | 确定性双阈值：`MIN_TOP_SCORE=5.0`、`MIN_ANSWERABILITY=0.43`；去除跨词边界噪声二元，避免误判 |
| 🧒 分龄 / 研学 / 双语讲解 | 儿童版 / 普通版 / 研学版 / English，保留事实 | 确定性模板改写，**展示 AI 改写与原始资料对照**并标注「AI 改写·事实以原文为准」 |
| 🔊 离线语音导览 | 按路线逐站生成讲解词，浏览器朗读 | 浏览器 **Web Speech API**（`SpeechSynthesisUtterance`, `lang=zh-CN`），无需联网或外部模型 |
| 🗺️ 点位与路线浏览 | 村落点位卡片 + 有序慢行导览路线 | 点位附关联资料标题与引用，路线给出步行时长与提示 |
| 🧰 人工审核台 | 来源类型分布、审核状态、审核人备注、版本记录 | 突出人机协同：资料经人工审核，版本可追溯 |
| 📏 可复现评估面板 | 示例问题集上的事实匹配/引用命中/拒答正确率/响应时间 | 离线确定性，评审可一键复算；**声明为示例测试集，不代表真实用户测试** |
| 🧩 可选 LLM 接地改写 | 仅在显式配置后调用外部模型，且被要求只依据给定资料 | 默认走确定性检索组装；模型失败自动回退规则，数值与事实仍以本地资料为准 |

**能力边界**：默认问答为确定性检索 + 规则组装，不是通用大模型自由生成；外部 LLM 仅作可选「接地改写」。作品创新重点在**可信资料组织、拒答机制、带引用交互与可复现评估**，而非模型本身。

## 二、快速开始

**环境要求**：Python 3.9+（仅用标准库，无需 `pip install` 任何包）。

### Windows
```bat
run.bat
```

### Linux / macOS
```bash
chmod +x run.sh
./run.sh
```

脚本会自动：① 校验/生成示例数据 → ② 运行冒烟测试 → ③ 启动服务并打开浏览器。

### 手动启动
```bash
python backend/server.py --port 8000
# 浏览器访问 http://127.0.0.1:8000/   （乡声 AI 导览——唯一产品入口，首屏即产品）
```

### 一键自测（评审复核用）
```bash
python tests/smoke_test.py     # 端到端检查，全通过退出码为 0
```

## 三、试试这些问题（主界面「AI 可信问答」）

可作答（命中资料并给出引用）：
- `青溪竹编的历史是怎样的？`

- `村里竹编传承人的手机号是多少？`

## 五、知识库与数据说明

- **文化资料库**（`data/culture_kb.json`，主方向）：以示例村落「青溪村·竹编技艺与古村文化」为单一自洽主题，收录 14 条资料（概况/非遗技艺/景点/民俗/农产品美食/实用信息）、5 个点位、1 条慢行路线与版本记录。**每条资料标注来源类型（公开资料整理/地方志体例改写/团队示例采写）、整理时间、授权范围与人工审核状态**；全部为示例/待实地核验内容，涉及真实地名、人物、机构时须另行取得授权并核验。
- **辅助看板数据**（`data/*.csv`、`counties.geojson`）：6 个虚构县的合成演示数据与示意地图，由 `data/gen_data.py` 以固定随机种子生成，仅用于演示数据可视化方法，不代表真实县域；另有世界银行 WDI 全国真实宏观序列，分开呈现。详见 `data/数据来源说明.txt`。
- 县域合成分析模块为**遗留辅助模块**，不作为作品主舞台；产品主页面（`/`）已不再提供任何入口链接，相关文件（`dashboard.html`/`app.js`/`styles.css` 等）暂予保留仅供参考，不属于本产品体验。

## 六、API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 乡声 AI 导览产品（唯一前端入口，加载 `app.css` + `guide.js`） |
| GET | `/api/guide/meta` | 导览产品元信息（村落/主题/声明/风格/审核汇总/示例问题） |
| GET/POST | `/api/guide/ask` | 检索增强问答（`?q=&style=&llm=` 或 JSON `{question,style,use_llm}`），带引用或拒答 |
| GET | `/api/guide/explain` | 讲解改写（`?entry_id=&style=&llm=`），返回改写文本 + 原文对照 + 引用 |
| GET | `/api/guide/pois` | 点位列表（含关联资料与引用）+ 有序路线 |
| GET | `/api/guide/narration` | 导览叙事脚本（供浏览器 Web Speech API 播报） |
| GET | `/api/guide/kb` | 知识库全量条目 + 人工审核台 + 来源分布 |
| GET | `/api/guide/eval` | 可复现评估面板 |
| GET | `/api/catalog` `/api/overview` `/api/index` `/api/map` `/api/geojson` `/api/insights` `/api/world-bank/*` `/api/ask` | 遗留数据看板 API（产品页不再调用，仅直接访问 `/dashboard.html` 时使用） |

## 七、安全与合规

- 服务**默认仅监听 `127.0.0.1`（本机回环）**，不对外暴露、无需鉴权；如需公网部署应另加反向代理与访问控制。
- 可选 LLM 功能通过环境变量 `RURAL_LLM_BASE` / `RURAL_LLM_KEY` / `RURAL_LLM_MODEL` 配置，默认关闭；密钥不写入代码库。提示词要求模型只依据给定资料改写、不得补充资料外事实。
- 语音播报使用浏览器内置 Web Speech API，不上传文本到第三方。
- 全部资料为团队整理的示例内容并标注来源与审核状态；AI 使用情况已在 `docs/AI使用说明.md` 中如实披露。
