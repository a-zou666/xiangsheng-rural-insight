# 原创性声明

本团队郑重声明：

参赛作品《乡声——乡村文化 AI 导览创作助手》由团队成员完成需求构思、本地文化资料的采写与核验、知识结构与交互设计、检索与拒答机制设计、系统集成、界面实现与参赛材料整理。作品使用了常见检索/统计/多指标评价方法、开源组件和公开数据；具体第三方资源及 AI 辅助情况在本声明和《AI 使用说明》中列明。本作品保留原「县域数据分析看板」作为辅助模块。

一、关于原创性

1. 文化知识库（`data/culture_kb.json`）由团队按公开资料风格整理编写，逐条标注来源类型、授权范围与人工审核状态，均为【示例/待实地核验】内容，不作为真实历史事实或已核实地方志引用；青溪村为示例村落设定。检索增强问答、拒答判定、分龄/研学/双语讲解改写与导览叙事由团队设计实现；BM25 检索、熵权法、TOPSIS、皮尔逊相关与回归等属于已有通用方法，不主张算法原创。默认问答为确定性检索与规则组装，不是通用大模型自由生成。团队应在提交前核对代码来源、贡献记录和竞赛对原创性/AI披露的具体要求。

2. 前端交互与可视化界面（乡声导览主界面及辅助看板）由团队自行设计与实现。语音导览使用浏览器内置 Web Speech API，不上传文本到第三方。

3. 辅助看板演示数据由生成器（`data/gen_data.py`、地图 `data/gen_map.py`）以固定随机种子合成，为虚构示例与示意边界。另使用 World Bank WDI 中国全国指标快照，属于第三方公开数据；指标代码、来源、口径与使用说明见 `data/数据来源说明.txt`。

二、关于第三方资源的使用

1. 作品使用了开源可视化库 **Apache ECharts**（Apache License 2.0），以本地离线方式打包用于图表渲染，相关版权归其原作者所有；除此之外未使用其他第三方运行时库。

2. 后端仅使用 Python 标准库，未引入任何需要 `pip` 安装的第三方包。

三、关于 AI 的使用

团队在开发过程中使用了 AI 编程助手进行辅助性工作（脚手架、调试建议、文档润色），所有产出均经团队人工审阅、修改与测试验证。运行时默认不调用外部模型；问数使用有限规则，统计与评价采用通用方法。模型调用仅在显式配置后启用。AI 使用情况已在《AI 使用说明》中如实披露。详见该文档。
