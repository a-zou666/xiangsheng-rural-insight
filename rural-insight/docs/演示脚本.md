# 演示脚本（答辩/录屏用，约 6 分钟）

> 目标：围绕乡声的**单一游览流程**演示——选择点位 → 收听/查看合适讲解版本 → 向导览提问（带引用作答或资料不足拒答）；并展示来源审核与可复现评估。强调首屏即产品（无推介式页面）、默认离线、确定性检索而非大模型自由生成，诚实说明资料为示例/待实地核验、尚未经真实用户验证。
> 建议录屏分辨率 1920×1080，浏览器全屏；语音演示前确认系统已安装中文 TTS 语音。

---

## 0. 启动准备（录屏前完成，不计入演示时长）

```bash
# Windows: run.bat ；Linux/macOS: ./run.sh ；或手动：
python backend/server.py --port 8000
```
浏览器打开 `http://127.0.0.1:8000/`，确认乡声产品页加载正常（唯一入口）。（可选）先运行 `python tests/smoke_test.py` 展示测试结果，数量以实际输出为准。

---

## 1. 开场与选题（约 35 秒）

> 「这是《乡声·乡村文化 AI 导览创作助手》。乡村非遗与农文旅现场常缺少适合不同年龄与语言、可快速获取且**可信**的讲解，而通用大模型容易编造地方历史。乡声**先检索团队整理并标注来源的本地资料，再组织带引用的答案；资料不足就明确拒答，不编造**。请注意：青溪村为示例村落设定，资料均为示例、待实地核验，尚未经真实用户验证。」

**画面：** 打开即是产品本身——左侧导览点位示意图与点位列表，右侧当前点位讲解与提问框，没有推介式首页。

---

## 2. 发现并选择点位（约 45 秒）

**操作：** 在左侧示意地图点击标记（或点列表项），依序选择「古樟树 → 竹编工坊 → 古廊桥」。

> 「游客从一张标出点位顺序与慢行路线的示意图进入。注意这是**示意坐标，不是真实地理位置**，我们不伪造实地照片或地图。点一个点位，右侧立即切换成该处的讲解。」

---

## 3. 讲解版本：分龄 / 研学 / 双语 + 收听（约 70 秒）

**操作：** 停在「竹编工坊」，切换讲解版本标签 普通版 → 儿童版 → 研学版 → English；点「▶ 收听讲解」；展开「对照原始资料」。

> 「同一处讲解可切换儿童版、研学版、双语版，**事实保持不变**；展开可随时并列查看原始资料，并标注『AI 改写·事实以原文为准』——AI 改写、人核事实。语音由浏览器内置 Web Speech API **本地合成，不联网、不调用外部模型**，作为音频导览的离线替代。」

---

## 4. 向导览提问：带引用作答（约 70 秒）

**操作：** 在提问框输入 `竹编是怎么做出来的？有哪些工序？`（或点情境示例）提交。

> 「它先用自研 BM25 检索本地资料，再确定性地组装答案。关键是**每条答案都带编号引用**——来源名称、来源类型、人工审核状态都列出来，可追溯、可核验；还显示置信度、检索最高分、主题覆盖率与用时。」

**操作：** 展开「检索过程与充分性判定」，展示命中/缺失主题词与阈值。

---

## 5. 资料不足就拒答（抗幻觉）（约 55 秒）

**操作：** 依次提问 `青溪村的常住人口有多少万？`、`量子计算的基本原理是什么？`。

> 「这两类问题资料库里没有依据。系统**不猜、不编**，直接回答『资料不足』并给出判定依据：相关度或主题覆盖率低于阈值。这正是相对纯大模型自由生成的核心可信优势。」

---

## 6. 来源审核 + 可复现评估 + 收尾（约 65 秒）

**操作：** 展开页面下方「资料来源与人工审核」（来源类型/审核状态/审核人/版本）与「可复现评估」（示例问题集指标）。

> 「每条资料的来源、审核状态和版本都透明可查，突出人机协同；评估面板在**团队示例问题集**上离线复算作答准确率、引用命中率、拒答正确率与响应时间，评审可一键复现——但**不代表真实用户测试**。整个后端只用 Python 标准库、零 pip 依赖、默认离线、一键启动、一键自测。资料为示例待核验，接入真实内容前需取得授权并核验。谢谢！」

> 说明：旧的县域数据看板已作为遗留模块，从产品中移除入口链接，不在本次演示范围内。

## 附：演示动线与问题清单（可按时间裁剪）

| 顺序 | 操作 | 展示点 |
|------|------|--------|
| 1 | 地图选点位：古樟树→竹编工坊→古廊桥 | 首屏即产品、示意坐标诚实披露 |
| 2 | 竹编工坊切换 普通/儿童/研学/English + ▶收听 | 分龄双语讲解 + 原文对照 + 离线语音 |
| 3 | 提问 `竹编是怎么做出来的？有哪些工序？` | 带引用作答 + 检索依据 |
| 4 | 提问 `竹编器物应该怎么保养？` | 命中保养条目 + 引用 |
| 5 | 提问 `青溪村的常住人口有多少万？` | 资料不足拒答 |
| 6 | 提问 `量子计算的基本原理是什么？` | 域外问题拒答 |

**常见问答预案：**
- 「和直接用大模型有什么区别？」→ 默认不调用大模型；答案来自对带来源资料的确定性检索组装，带引用、可复算；资料不足即拒答，避免编造。外部模型仅可选用于接地改写且被约束只依据给定资料。
- 「资料是真的吗？」→ 青溪村为示例村落设定，资料由团队按公开资料风格整理、逐条标注来源与审核状态，均为示例/待实地核验，不作真实史实引用；接入真实内容前需授权与核验。
- 「拒答阈值怎么定的？」→ 相关度下限与按 IDF 加权的主题覆盖率下限两道确定性阈值，判定过程与命中/缺失词都在界面展示，可核验。
- 「评估结果可信吗？」→ 离线确定性、可一键复算；但为团队示例测试集，不代表真实用户测试，后续需做真实用户任务测试。
- 「语音要联网吗？」→ 不需要，使用浏览器内置 Web Speech API 本地合成。
- 「那个数据看板呢？」→ 旧县域数据看板是遗留辅助模块，已从产品移除入口，仅文件保留供参考，不属于本产品体验。
